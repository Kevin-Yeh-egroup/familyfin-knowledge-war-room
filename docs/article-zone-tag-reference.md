# 文章專區標籤參考

來源：InfoCenter「好理家在文章管理區」文章管理正式索引  
更新時間：2026-06-02  
用途：作為新增建議、agent 產稿、核准分類與後續入庫的標籤依據

## 一、標籤使用原則

新增建議不得自行發明分類名稱。

每一篇建議文章至少需要：

- 1 個文章受眾標籤
- 1 個主要知識庫標籤
- 必要時可加 1-2 個次要知識庫標籤

優先選擇文章真正要解決的問題，不只選文章提到的素材。

例如：

- 租金補貼文章若重點是補助與居住穩定，主要標籤應為 `主要問題彙編-政府救助資源`。
- 債務協商文章若重點是還款壓力與協商流程，主要標籤應為 `主要問題彙編-債務`。
- 詐騙後復原若寫給社工並聚焦評估介入，主要標籤可為 `評估與輔導觀點-專業知能`，次要標籤才放 `家庭重大事件-詐騙`。

## 五、目前可優先補強的判斷方式

標籤量少不一定代表內容缺口，但可作為 source scout 的優先檢查線索。

後續 agent 產生新增建議時，應先檢查：

- 該標籤既有文章是否已經很多
- 新文章是否有新的台灣資料、政策變動或真實案例
- 是否能補上一般民眾版或社工版其中一邊不足
- 是否能用正式標籤放入現有知識庫，不需要新增分類
