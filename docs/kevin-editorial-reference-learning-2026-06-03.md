# Kevin 修稿樣本學習卡

日期：2026-06-03

來源：Kevin 提供的人工調整稿，作為好理家在一般民眾文章生成參考。

## 不是要照抄

這份學習卡只保存寫作判斷，不保存完整參考稿。

Agent 後續生成文章時，應學習 Kevin 的修稿方向，但不得把參考稿當成固定模板或逐句複製。

## 學到的寫作口味

1. 開頭先抓生活機制。

不要先說「這是一個重要議題」。

要先讓讀者看見生活裡真正卡住人的東西，例如日期準時、帳單不等人、收入和照顧同時變少、時間每天被照顧吃掉。

2. 數字要推動判讀。

數字不是用來顯示文章有資料，而是讓讀者看見前後差異。

好的數字會回答：

- 原本剩多少？
- 補助後多多少？
- 能少借幾次？
- 能撐幾天？
- 哪一筆支出真正造成卡住？

3. 政策要翻成生活用途。

補助金額不能只寫年度或月額。

要寫成讀者能想像的用途，例如兩週通勤、一次診所自費、孩子制服、少一次刷卡補洞、幾天房租緩衝。

4. 用日期、金額、順序整理壓力。

家庭財務常不是總額問題，而是日期和順序問題。

文章要常問：

- 哪一天收入進來？
- 哪一天房租或扣款出去？
- 哪一筆不能斷？
- 哪一筆可以延？
- 哪一筆會變成新債？

5. 列點可以出現，但不要變講義。

短列點可以整理三個卡點、三個數字、三個順序。

但列點後一定要回到生活壓力與選擇，不要停在教學條列。

6. 結尾要回到生活選擇。

不要收成口號，也不要過度雞湯。

好的結尾會讓讀者感覺：

- 原來不是我不努力。
- 原來壓力有結構。
- 我可以先看懂日期、金額、順序與缺口。
- 生活不一定馬上變好，但可以先保留一點可以呼吸的空間。

7. 可見正文不要出現內部轉場。

「前後差異」可以是內部規劃語，但不一定是給讀者看的文字。

正文若出現「示意前後差異」「示意看前後差異」，讀起來會像作者備註或講義語。

要改成更自然的生活轉場，例如：

- 把調整前後攤開看。
- 把時間差算進去。
- 把每月結餘拆開看。
- 把照顧費和醫療費攤開。

8. 結尾要有落點。

Kevin 回饋：有些文章結尾偏弱，會有爛尾或詞不達意的感覺。

因此結尾要額外檢查：

- 是否回扣第一段的生活矛盾。
- 是否收成一個清楚判斷。
- 是否讓讀者知道要先看日期、金額、順序、支出缺口或支持來源中的哪一個。
- 是否避免只用抽象希望、漂亮話或新概念收尾。

## Agent 檢查問題

- 第一段是否有抓到生活機制？
- 政策與數字是否被翻成日常用途？
- 是否至少有一組前後差異？
- 改善關鍵是否清楚，不只是「要盤點」？
- 是否有日期、金額、順序或時間差？
- 結尾是否回到生活選擇，而不是抽象鼓勵？
- 結尾最後一句是否有明確落點？
- 正文是否把「示意前後差異」這類內部語改成自然轉場？
