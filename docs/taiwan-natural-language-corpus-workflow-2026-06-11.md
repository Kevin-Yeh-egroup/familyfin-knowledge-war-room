# 2026-06-11 台灣自然語感觀察工作流

## 目的

文章不應只靠禁用詞表降低 AI 感，也不能只參考官方說明。

同一句話在不同脈絡可能自然，也可能生硬。真正需要建立的是「台灣一般民眾如何描述生活財務壓力」的語感判斷能力，並讓 agent 在生成前、二修時與整批檢查時都能使用。

## 優先順序

1. 真實讀者回饋與公共討論
   - 包含文章留言、YouTube 留言、Dcard、PTT、Threads 等公開討論。
   - 用來學「一般人怎麼說」「哪裡會卡」「問問題時會用什麼句子」。

2. 好理家在審核通過稿與總編輯駁回意見
   - 用來學好理家在標準。
   - 判斷一篇文章是否符合投稿需求、財務教育目的與助人工作情境。

3. 台灣新聞與生活型報導
   - 用來學事件敘述、生活壓力、段落開場與社會脈絡說法。

4. 官方與金融教育資料
   - 只用來確認事實、正式名詞、制度流程與基本金融教育架構。
   - 不作為自然語氣的主要來源。

## 取樣來源

1. 真實回饋與公共討論
   - 最高優先語感來源。
   - 觀察民眾怎麼描述焦慮、困惑、卡關與不公平感。
   - 只保存匿名、聚合後的語感規則，不保存帳號、個資或大量逐字內容。

2. 好理家在審核通過稿與總編輯駁回意見
   - 最高優先來源。
   - 用來判斷好理家在接受的文章節奏、段落推進、結尾力道與受眾角度。

3. 台灣金融教育與政府說明
   - 用來確認正式用語。
   - 例如「養成記帳習慣」「檢討支出金額」「擬定收支計畫」「從收支平衡做起」「定期檢查預算」。
   - 不直接模仿官方口吻。

4. 台灣新聞與生活型報導
   - 用來觀察一般讀者熟悉的事件敘述與生活壓力寫法。
   - 不複製原文，只摘錄語氣特徵、段落節奏與常用動詞。

5. YouTube 留言、社群回饋與文章留言
   - 用來觀察一般人自然說法。
   - 只做匿名、聚合式觀察，不記錄帳號、個資或可識別內容。
   - 只保存「語感規則」與「常見說法類型」，不保存大量原文。

6. 記帳工具、家庭收支文章與使用者評論
   - 用來觀察民眾談記帳、收支、預算、帳務核對、固定支出時的自然用語。

## 觀察欄位

每次取樣後，不保存長篇原文，而是整理成下列欄位：

- sourceType：政府說明、新聞、生活文章、留言、好理家稿件、審稿意見。
- topic：房租、補貼、債務、托育、長照、詐騙、減班等。
- naturalTerms：自然常用詞，例如記帳、收支、帳務核對、固定支出、月底、刷卡、補洞。
- awkwardTerms：容易生硬的說法，例如把抽象概念硬塞進生活句、公告式資源介紹、翻譯腔比喻。
- sentenceMove：句子如何推進，例如先說生活困境，再把收入與支出擺在一起看。
- readerEffect：讀者會不會容易代入，是否知道下一步可以做什麼。
- rewriteCandidates：同一句意思的 3 到 5 種台灣自然說法。
- selectedCandidate：最後採用的句子。
- rejectedReason：未採用候選句的原因，例如仍像公告、仍像 AI、太像顧問、一般人不會這樣說、行動不合常理。
- behaviorRealism：一般台灣讀者是否真的可能照做，是否有合約、面子、人情壓力、權力不對等或害怕被貼標籤的阻力。

## Agent 分工

1. corpus_scout
   - 找台灣公開討論與真實回饋來源。
   - 標註來源類型與可用目的。
   - 優先找讀者留言、社群討論、新聞留言與實際問答。

2. expression_miner
   - 從來源整理自然詞組、常見句型與不自然風險。
   - 不保存大量原文。
   - 特別記錄「民眾怎麼抱怨」「怎麼問下一步」「怎麼描述錢不夠」。

3. taiwan_voice_mapper
   - 把文章中的生硬句改成 3 種不同語氣。
   - 分成一般民眾、助人工作者、政策說明三種語境。

4. public_reader_editor
   - 判斷一般民眾是否看得懂、是否願意繼續讀。
   - 優先選擇生活語言，不選最漂亮或最抽象的句子。

5. final_voice_gate
   - 用朗讀感檢查。
   - 問：「這句話一般台灣人會這樣說嗎？」「像不像公告？」「像不像 AI 在硬轉接？」

6. behavior_realism_reviewer
   - 檢查文章提出的行動是否符合一般台灣人的生活習性。
   - 問：「正常人真的會這樣做嗎？」「會不會因為合約、面子、怕被房東貼標籤、怕家人知道而不敢做？」「如果這個行動很難，文章有沒有放在正確順序，而不是寫得像很容易？」

## 本次語感修正

原句：

把補貼放進月曆裡看，感覺會比較清楚。

問題：

- 「放進月曆裡看」有翻譯腔。
- 想表達日期與現金流，但一般讀者比較常說記帳、收支、核對、放在一起看。
- 句子有畫面，但不夠像台灣一般民眾的財務描述。

採用句：

做一次簡單的收支核對，會比較清楚。把收入、房租和可能進來的補貼放在同一張表裡，這個家庭後來核定每月補貼3,200元，房租壓力會從22,000元降到18,800元。

## 真實回饋取樣後的寫作提醒

租金補貼相關討論裡，民眾不只在問制度內容，也常在表達：

- 已經核定或已經發款，後來卻被要求補件、追回或重新確認時的錯愕。
- 一次要補繳或返還大筆金額時，會先問「我現在去哪裡生錢」或「能不能分期」。
- 對房東、租金、稅務與補貼之間關係的疑惑。
- 對「當初可以申請，後來又被追討」這類時間差的挫折。
- 對房租漲、補貼是否真的進到租客身上的不信任感。

因此文章不能只寫「可以申請補貼」。

更自然的寫法要回到讀者真正會問的問題：

- 這筆補貼是幫下個月減壓，還是能處理這個月已經到期的房租？
- 如果後來被要求補件或追繳，家裡要先準備哪一筆錢？
- 如果一次繳不出來，能不能問分期或找地方社福窗口？
- 如果房東因此調整房租，家庭的收支表會不會反而更緊？

## 行動常理檢查

語感自然還不夠。

文章提出的行動也要符合一般人的行為習慣。以「跟房東協調延期繳房租」為例，這件事不是不能寫，但不能寫成理所當然的第一步。對很多租屋家庭來說，這會牽涉：

- 租約已經寫好付款日。
- 怕被房東認為信用不好。
- 不想讓對方知道家裡現金流出問題。
- 怕被催、被刁難、被要求搬走或下次不續約。
- 面子與關係壓力。
- 房東自己也可能有房貸或其他支出。

所以文章比較合理的寫法是：

- 先看房租日前實際差額。
- 先分清楚哪一筆支出不能斷，哪一筆可以延後。
- 先查可用的急難、地方社福或可信任支援。
- 先準備下一次房租的預留帳戶或固定扣款安排。
- 如果真的避不開，再看租約與可能違約成本，並在到期前用清楚、可留紀錄的方式確認付款日期。

避免寫成：

- 直接跟房東談就好。
- 請房東延後幾天就解決了。
- 只要溝通就能移開壓力。

較自然的句型：

- 很多人其實不會想開口跟房東談延期，這很正常。因為租約寫在那裡，也怕一開口就被貼上「繳不出房租」的標籤。
- 如果真的差在那幾天，先不要把希望全部放在房東願不願意等。比較穩的是先算出差額，再看能不能從急難協助、短期可靠支援或下一次預留房租來處理。
- 真的需要延後付款時，也不要等房東來催才說。至少要先看租約、確認自己能付的日期，並留下清楚紀錄。

可替換候選：

- 如果平常有記帳，這時候就能看出補貼到底補到哪一段壓力。
- 把收入、房租和可能進來的補貼擺在一起看，差距會比較明顯。
- 先做一次帳務核對，才知道補貼是幫下個月減壓，還是這個月仍要先找其他方法補缺口。
- 把這個月會進來的錢和一定要出去的錢列在一起，就會看見房租日前真正差多少。

## 後續使用規則

- 不建立永久禁用詞表作為唯一判斷。
- 每次文章生成至少提出 3 個自然說法候選。
- final_voice_gate 要選「讀者會自然讀下去」的版本，不選最概念完整但最生硬的版本。
- 如果句子看似漂亮但不像一般台灣語氣，退回 taiwan_voice_mapper 重寫。
- 來源文字只做語感觀察與規則化，不直接複製成文章正文。
