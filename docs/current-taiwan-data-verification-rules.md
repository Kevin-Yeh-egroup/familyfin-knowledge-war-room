# 台灣最新資料與補助規範查核規則

建立日期：2026-06-02

## 適用範圍

凡文章涉及下列內容，都必須先查核目前有效版本：

- 補助、津貼、補貼、救助、計畫、專案。
- 申請資格、申請期限、補助金額、補助期間。
- 中央政府政策、地方政府規範、縣市申辦窗口。
- 法規、行政規則、主管機關公告。
- 統計數據、年度預算、核定戶數、受益人數。

## 必查條件

每篇文章引用補助或政策時，至少要確認：

- 資料是否為目前最新公告。
- 適用年度，例如 115 年度、2026 年度或最新受理年度。
- 主管機關，例如衛福部、內政部、勞動部、金管會、縣市政府。
- 中央與地方是否規範不同。
- 申請資格、金額、期限是否仍有效。
- 是否有縣市差異、身分差異或加碼條件。
- 查核日期。

## 寫作規則

- 不可沿用過去年份的補助金額或計畫名稱，除非文章明確說明那是歷史背景。
- 不可把中央規範寫成全國所有地方都完全相同。
- 不可把單一縣市規則寫成全台一致。
- 若地方差異大，文章應寫成「需向所在地縣市政府或主管機關確認」。
- 若最新資料無法確認，文章不得標示為「可投稿」，應退修為 `needs_more_evidence`。
- 若資料來源頁沒有更新日期，需在事實查核紀錄中註明「來源未明示更新日期」。

## 來源優先順序

1. 主管機關官方網站或法規資料庫。
2. 中央部會新聞稿、公告、專區頁。
3. 地方政府官方頁面。
4. 政府資料開放平台、主計總處、警政署、勞動部等統計。
5. 可信新聞媒體，用於案例與輔助說明，不得單獨作為政策有效性的唯一依據。

## 退修標準

文章若出現下列情況，必須退修：

- 引用過期年度補助，卻寫成目前有效。
- 只引用新聞，未回查主管機關公告。
- 未標示適用年度、主管機關或查核日期。
- 中央與地方規範混寫。
- 補助金額或資格沒有來源。
- 使用「一定可以申請」「保證核准」等過度承諾。
