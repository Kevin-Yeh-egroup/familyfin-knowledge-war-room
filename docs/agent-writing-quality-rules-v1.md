# 好理家在 Agent 寫作品質規則 v1

來源：InfoCenter chronological learning packs 001-005  
樣本：122 篇可學正文  
狀態：公開版規則，不含原始文章全文

## 一、核心判斷

好理家在的文章不是百科，也不是單純理財教學。

好文章要讓讀者看懂：

- 表面問題是什麼
- 為什麼不能只從行為理解
- 生活條件如何限制選擇
- 風險如何累積
- 下一步可以先盤點什麼

## 二、通過稿共同特徵

通過稿通常有四個特徵。

第一，有生活情境。

文章會從租屋、家庭、債務、保險、詐騙、照顧、就業或補助等場景切入，讓讀者知道這不是抽象議題。

第二，有制度或實務連結。

文章會連到台灣法律、政府資源、金融機構流程、社福制度、醫療資源或實際申請窗口。

第三，有問題重新框架。

它不只說「要記帳」「要防詐」「要保險」，而是指出為什麼人會在壓力下失去判斷與調整空間。

第四，有可行下一步。

下一步不一定是完整解法，但至少要能讓讀者知道可以查哪裡、問誰、盤點什麼。

## 三、駁回稿常見風險

駁回稿常見風險不是主題不好，而是文章形狀不對。

需要避免：

- 像資料整理，不像知識文章
- 只有優缺點，沒有生活處境
- 只有成本效益，沒有壓力與選擇
- 只有法律或制度，沒有讀者理解
- 只有案例刺激，沒有回到可學習的判讀
- 只有建議，沒有說明為什麼人會卡住

## 四、一般民眾版寫法

一般民眾版要先理解，再整理。

必須做到：

- 開頭直接切入生活中的矛盾或壓力
- 少用專業術語
- 多用短句與換行
- 把問題從個人能力改寫成生活條件
- 讓讀者知道自己不是只有不努力
- 結尾回到重新理解與可盤點的下一步

## 五、社工版寫法

社工版要把問題轉成判讀與介入。

必須做到：

- 指出表象與結構差異
- 說明社工容易誤判的地方
- 把金錢、家庭、工作、風險與支持系統一起看
- 提供評估焦點的轉換
- 提供可用於實務的提問或盤點方向
- 避免把文章寫成資源清單或教科書

## 六、真實案例與資料規則

新增建議文章必須先有資料來源。

優先順序：

1. 台灣官方統計、政府公開資料
2. 法律、政策、制度原始來源
3. 負責機關或地方政府頁面
4. 專業組織、學術或 NGO 報告
5. 可靠新聞案例

使用案例時：

- 不臆測當事人動機
- 不補寫未證實細節
- 不把單一事件當成普遍結論
- 去識別化
- 說明案例限制
- 將案例轉成讀者可學習的判讀

## 七、Agent 生成流程

1. `source_scout`：找台灣資料、制度、統計、新聞案例。
2. `knowledge_gap_mapper`：比對既有分類與文章缺口。
3. `article_pattern_miner`：確認是否符合好理家在寫法。
4. `public_writer` 或 `social_work_writer`：依受眾產稿。
5. `fact_case_reviewer`：檢查資料、案例、數字與過度推論。
6. `quality_reviewer`：檢查 prompt fit、語氣、結構、下一步。
7. `approval_packager`：包成 Kevin 可核准的新增建議。
