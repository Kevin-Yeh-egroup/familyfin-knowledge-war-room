# 好理家在可投稿文章生成標準 v2

更新日期：2026-06-02

## 目標

每週自動產出的內容不再只是「新增建議」，而是 10 篇不同主題、可閱讀全文、可人工審核、可直接投稿修整的文章包。

文章需符合三個條件：

- 對好理家在知識庫有補位價值。
- 對一般民眾或社工讀者有清楚讀者定位。
- 有台灣資料、真實案例來源或可查核的綜合情境，不只是概念描述。

## 必過門檻

- 正文扣除 SEO 欄位、來源、FAQ、agent 討論紀錄後，仍需超過 2000 字。
- 每篇至少引用 2 個台灣脈絡來源，優先順序為政府、統計、金融機構、法院、可信新聞。
- 每篇必須有讀者版本：一般民眾或社工。
- 每篇必須對應正式文章專區標籤：讀者標籤、主要知識分類、次要標籤。
- 每篇必須包含 SEO Title、Meta Description、Slug、搜尋意圖、主要關鍵字、次要關鍵字、AIO 摘要與 FAQ。
- 每篇必須保留 agent 討論摘要，說明為什麼選這個主題、如何避免誇張不實、為什麼符合好理家在風格。
- 案例只能使用公開新聞、政府公開資料、可查核來源，或明確標示為綜合情境。

## 文章應有的內容層次

一般民眾版：

- 先讓讀者感覺被理解。
- 從表面問題走到生活條件與壓力結構。
- 不責備、不雞湯、不把財務問題簡化成不努力。
- 結尾回到「重新理解自己與生活選擇」。

社工版：

- 從實務現場常見誤判切入。
- 說明表面現象背後的結構與風險。
- 帶出評估、盤點、提問、轉譯與支持系統。
- 結尾收束成清楚的實務立場。

## 每週 10 篇主題配比

- 生活壓力型：4 篇，例如租屋、單親、青年、預備金。
- 資源制度型：3 篇，例如補助、債務協商、社會救助。
- 風險預防型：2 篇，例如詐騙、高齡風險。
- 社工實務判讀型：1 篇以上，例如收入中斷、長照、資源轉譯。

## Agent 討論流程

每篇文章至少經過下列角色檢查：

- `source_scout`：找台灣官方資料、統計、新聞或案例。
- `tag_mapper`：對應文章專區正式標籤。
- `article_pattern_miner`：比對已學成功與退修樣本，避免風格錯位。
- `public_writer` 或 `social_work_writer`：依讀者版本寫稿。
- `fact_case_reviewer`：檢查資料年份、數字、政策、案例是否可查。
- `seo_aio_reviewer`：檢查搜尋意圖、FAQ、AIO 摘要與標題。
- `quality_reviewer`：判定可投稿、退修或駁回。

## 退修與駁回原因

- 字數不足，或用重複內容灌字數。
- 只有概念，沒有資料、案例、台灣制度或生活情境。
- 使用未查核故事或過度戲劇化案例。
- 語氣像投資課、勵志文、業配文或責備讀者。
- 一般民眾版太專業，社工版又太像衛教短文。
- SEO/AIO 欄位不足。
- 標籤使用自創分類，未對應文章專區正式標籤。
- 承諾可以解決債務、保證補助成功、暗示單一方法必然有效。

## 審核台欄位

每篇文章在審核台需顯示：

- 標題、讀者版本、主要標籤、次要標籤。
- 正文字數與品質狀態。
- SEO title、meta description、slug、搜尋意圖。
- 資料來源清單。
- Agent 討論摘要。
- 全文預覽。
- 核准投稿、退修、駁回。
- 核准後依主要標籤分類存放並可匯出。
