# 2026-06-03 角色錯亂與一般民眾預設修正日誌

## 問題

Kevin 指出首批生成文章有重大角色錯亂：

- 正文混入對作者、編輯或 agent 的寫作建議。
- 例如「對一般民眾版本來說」「文章最後也應」「如果這篇文章要投稿」這類句子被放進正文。
- 這會讓讀者看見生成痕跡，進而不信任文章。

此問題不是單篇瑕疵，而是生成流程沒有把「內部規劃」與「讀者正文」硬切開。

## 掃描結果

新增 `tools/audit-article-role-integrity.js` 後，掃描 `articles/2026-06-02-weekly-pack`：

- 掃描文章：10 篇
- 命中問題：63 筆
- 正文後台語：11 筆
- 預設一般民眾流程下不應出現的社工語氣：48 筆
- 非預設受眾 metadata：4 筆

因此首批 10 篇文章降級為「需重生，不可直接投稿」。

## 本次修正

### 1. 新增 fatal gate

新增 `gate-11-role-integrity`：

- 名稱：角色一致與內部語言隔離關卡
- 嚴重度：fatal
- 任何正文出現作者建議、審稿語、投稿語、知識庫語、讀者版本語或 agent 討論痕跡，都應退回重寫。

### 2. 預設全部生成一般民眾版

後續文章生成預設：

- 一律生成一般民眾版。
- 只有 Kevin 明確提出社工版時，才啟用社工版。
- 未明確指定時，不得出現社工評估、介入、服務對象、個案、助人工作者等語氣。

### 3. 新增 role_leak_reviewer

每次文章包生成後，必須掃描：

- 這篇文章
- 本文可以
- 本文應
- 文章最後
- 文章發展
- 對一般民眾版而言
- 如果這篇要投稿
- 如果這篇文章要用在知識庫
- 可以提醒讀者
- 建議每篇
- 好理家在文章的重要任務
- 知識文章要做到
- 審稿
- 投稿
- agent

上述語句若出現在正文，直接退修。
