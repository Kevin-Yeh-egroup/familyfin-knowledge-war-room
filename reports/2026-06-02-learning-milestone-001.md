## 學習發現

第一，通過稿多數會把生活情境放在前面。

成功文章常見切入方式是家庭、債務、詐騙、保險、補助、醫療、租屋、子女教養或工作變動。這些文章不是只談觀念，而是把制度或知識接到讀者真的會遇到的壓力。

第二，駁回稿常見問題不是沒有資訊，而是太像資料整理。

駁回稿中有些主題本身很重要，例如信用、在職專班、二房東、夫妻財務、消費者債務清理。但文章若停在定義、利弊、成本分析或專業資訊，較難形成好理家在需要的「重新看懂處境」。

第三，社工版文章需要更明確的介入語言。

只說資源、條件或法律，不等於社工文章。社工版需要指出社工怎麼看、可能看錯哪裡、如何盤點風險、如何陪服務對象轉譯現實限制。

第四，真實案例有效，但需要去識別化與倫理邊界。

本批次中發現部分文章含有會談或個案資料痕跡。這些資料可以作為內部學習，但不能進入公開 repo 或 Vercel 頁面。後續 agent 生成案例時，只能使用公開新聞、官方案例、已授權素材或清楚標示的示意情境。

第五，審核意見欄位仍是缺口。

目前能穩定取得審核狀態，但文字型駁回建議尚未出現在已讀 API 欄位。後續要從頁面互動、其他 API 或人工導出路徑補齊，才可能建立更精準的「駁回原因模型」。
